## Problem Statement
Beginners learning programming repeatedly solve the same basic number problems (prime check, factors, GCD, Fibonacci, binary conversion) as separate, disconnected programs. There is no single, easy, crash-proof tool that gathers these problems in one place, lets a student verify answers quickly, and shows how small functions combine into a larger program.

## Scope of the Project
**In scope**
- A console-based, menu-driven Python application with 14 mathematical utilities
- Modular design (7 modules) using functions, loops, conditions and lists
- Input validation and error handling for all user inputs
- Unit tests for all core functions

**Out of scope**
- Graphical interface, database or network features
- Very large numbers / high-performance number crunching
- Symbolic algebra or calculus

## Target Users
- First-year engineering / computer science students practising programming basics
- Teachers who want a quick demo of core algorithms
- Anyone who needs fast number checks (prime, factors, GCD, binary)

## High-Level Features
1. **Number Theory** – prime check, factors, prime factorization, GCD, smallest divisor
2. **Sequences** – factorial and Fibonacci series
3. **Converters** – reverse number, decimal to binary, character to ASCII value
4. **Math Operations** – square root, power, random number generator
5. **Full Analysis** – one-shot report combining several functions
6. **Robust input handling** – invalid input never crashes the program
